# Noteify

**A Chrome extension that speaks the UI changes a screen reader would otherwise miss.**

Built for the BitNBuild '26 hackathon by the team **IKEA**
*Princess & Hanz*

**Web Development theme**

*"Interfaces That Change Silently"* — interfaces rebuild themselves constantly
as people use them, and each silent change a sighted user simply sees leaves
someone listening with no idea anything happened at all.

------------------------------------------------------

## Why we built this

Modern websites change constantly without a page reload: a notification
appears, a popup appears, etc. A user that can see
catches all of this instantly, just by looking. A blind or low-vision user
relying on a screen reader (like **NVDA** — NonVisual Desktop Access) gets
none of it, unless the developer specifically coded the page to announce
those changes with ARIA live regions. Most sites don't.

That leaves screen reader users in one of two bad situations:

1. **Silence** — changes happen and they never find out. They miss a "wrong
   password" alert, a new message, a discount popup, a form error.
2. **Overload** — if a site *does* announce everything, and announces it
   badly, a ton of notifications turns into a bunch of uninterruptible
   speech that talks over itself and over the user's own screen reader
   commands. This is exhausting and can only be very overstimulating.

Noteify sits in the middle: it watches for exactly these kinds of silent UI
changes, and reports them to NVDA in a way that is **informative without
being overwhelming.** Small updates are just quietly announced. A flood of
updates gets held back and offered as a choice, instead of being dumped on
the user all at once, the user is given a choice.

## Tech stack

1. Extension : Chrome Extension, **Manifest V3**, vanilla JavaScript content script

2. Accessibility layer : Native browser **ARIA live regions** (`aria-live="assertive"` / `"polite"`), `MutationObserver` API 

3. Screen reader : **NVDA** (NonVisual Desktop Access) the free, open-source Windows screen reader Noteify was built as an add on for

4. Test/demo page : Plain HTML, CSS, JavaScript

5. Storage : `chrome.storage.local` (per-page last-visit tracking)

## Features

### Alt+S — On-Demand Summary
Announces page context to NVDA on command without clutter:
* Time since last visit
* Status of the info modal
* Count of unread notifications with options to read, ignore, or clear
* Mute status of automatic announcements

### Alt+M — Mute Toggle
Toggles automatic announcements on or off so users can prevent overstimulation on chatty pages while retaining manual Alt+S checks.

### Flood Protection
Prevents speech overlap when multiple notifications trigger at once:
* **1–2 notifications** within 2 seconds: Polite sequential announcements.
* **3+ notifications** within 2 seconds: Mutes automatic reading and prompts: *"there are new notifications, would you like to hear them?"*
* **Alt+Y**: Play preview
* **Alt+N**: Dismiss for later

### Alt+C — Quick Clear / Close
Closes open modals or clears unread notifications instantly without requiring keyboard focus hunting.

### Alt+Y — Read Modal Contents
Reads the text inside an active modal before giving the option to dismiss it with Alt+C.

### Dual ARIA Live Regions & Targeted Observers
Prevents feedback loops and self-narration:

* **Assertive region**: Reserved for explicit user hotkey actions.
* **Polite region**: Used for queued automatic updates.
* **Scoped observers**: Monitors target IDs (`#notif-list`, `#btn-enlarge`, `#info-modal`, `#toast`) instead of `document.body`.

### Demo Page Guard
Detects test page element IDs on load and stays dormant on all other sites without manual toggling.

## Setup instructions

### 1. Install NVDA (if you don't already have it)
Noteify is built to work alongside NVDA, the free screen reader for
Windows.
- Download: https://www.nvaccess.org/download/
- Start it with **Ctrl+Alt+N**
- Press **CapsLock** any time to make it stop talking mid-sentence

### 2. Load the Noteify extension into Chrome
1. Open Chrome and go to **[chrome://extensions](chrome://extensions)**
2. Turn on **Developer mode** using the toggle in the top-right corner
3. Click **Load unpacked**
4. Select the folder titled **`NOTEIFY`** (this is the extension itself —
   don't select the whole project folder, just `NOTEIFY`)
5. Noteify should now appear in your extensions list with its icon

### 3. Open the test page
1. Open **https://pjamila55.github.io/test-page/** in Chrome
2. Make sure NVDA is running
3. Hit **Alt+S** for your first update

## Keyboard shortcuts

| Shortcut |
| **Alt+S** | Check for updates: time since last visit, current modal state, current unread notifications |
| **Alt+M** | Mute / unmute automatic announcements |
| **Alt+Y** | Read a pending notification flood, or read the open modal's contents |
| **Alt+N** | Leave a pending notification flood for later |
| **Alt+C** | Close the info modal if open, and/or clear all notifications |
| **Alt+H** | Hear the full command list again |

## Known limitations / possible future work
- Currently only activates on the included test dashboard's exact DOM
  structure — a production version would need a way to describe *any*
  site's UI regions, not just this one
- Mute state and live-region setup reset on page reload (not persisted)
- Only tested against NVDA on Chrome; other screen readers (JAWS,
  VoiceOver) and other browsers haven't been verified
